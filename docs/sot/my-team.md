# My Team

App-internal source of truth for the season roster hub (`/my-team`). Distinct from Cheat Sheets’ browser-only **My team** checklist (`localStorage`).

## Nav and routes

- Nav: **My Team** sits to the right of Strategy (`client/src/components/Layout.tsx`).
- `/my-team` → `MyTeamPage` — ESPN-inspired roster tables + **Sync roster**.
- Empty state / **Update connection** link to Import → **Import League** (`/import#import-league`).

## Import League (under Import)

On `/import`, below **Import ESPN Drafts** (`.docx` history):

1. League ID (default `1735901`) + season.
2. Paste `espn_s2` + `SWID` once (collapsible how-to), or use `.env` / previously saved secrets.
3. **Preview league** → pick your team (suggested from `league-config` `userTeamName`).
4. **Import to My Team** — shown as soon as a team is selected. Writes `data/my-team/{season}.json`, saves cookies to gitignored `data/secrets/espn-auth.json` when pasted, navigates to `/my-team`.

Roster preview: two columns (**Starters** / **Bench**), compact tiles, lineup/pos pills color-coded with `.pos-*`. Injury labels as plain colored text via `statusBadge`. Team dropdown uses the same text size as preview rows with a CSS chevron.

Roster entries parse `entry.player` or `entry.playerPoolEntry.player` (ESPN mRoster nesting).

## My Team page

Page header shows `teamName` in the same weight/line-height style as the bio modal player name, at a larger size (`2.3rem` vs bio `1.45rem`). **Lineup** / **Stats** / **Players** pills sit above the tables (`MyTeamPage`). Default is Lineup. First open of **Stats** (season-stats fetch) and **Players** (free-agent board) use the same bouncing-squares `PageLoading` as other subpages (sayings: “Pulling the box score…” / “Scouting the wire…”); initial My Team load uses “Checking the locker room…”.

### Lineup view

Three sections when present: **Starters**, **Bench**, **IR**. Each table has grouped headers in roster order (not sortable — keep slot order). Shared fixed `colgroup` (Slot / Player / Opp / Status + equal numeric cols) so stacked tables keep the same column X. Numeric columns right-align. Starters always show the default ESPN slot list (QB · 2 RB · 2 WR · TE · FLEX · D/ST · K); when ESPN omits an empty slot from `mRoster`, the row still appears with **Empty** for the name and **—** for Opp/Status/stats (no calendar / FA / VS toggles). Last Bench/IR data row uses `mt-row-edge` to drop its bottom divider (SOS/VS/FA expand rows still trail it), so it doesn’t double the table wrap border; Starters keep a divider above **Totals**.

**SOS expand:** A calendar icon sits to the right of the injury label (or name when healthy); tooltip / aria label **Upcoming Schedule**. Open and hover share the soft green border/fill badge (not green stroke alone). Closed hover raises the icon slightly; open/selected stays flat. Press dips it down then returns on release. Lineup body cells are top-aligned so slot labels (especially **D/ST** / **K**) stay on the name/calendar line. Click toggles a remaining-slate strip under that player (**current week → season end** only — prior weeks are omitted) with **Upcoming Schedule:** on its own top-left line, then a flush row for the league-host label (**ESPN** / SLEEPER / CBS, plus **BLENDED** when shown) with extra gap before the scrolling week squares; week cells use the same square size as Tools → SOS Offense/Defense (`~3.25×2.55rem`, opp over rank); the current week number stays the same size with accent-green text on a translucent green circle (no **Current Week** text label). **Show All:** boxed control (calendar + **VS** icon checkboxes, no text labels, **Apply** inside the same box): on Lineup / Stats it sits right-aligned on the same row as Lineup / Stats / Players; on Players it sits left of the player search. Draft checkbox toggles alone do not open or close strips; **Apply** opens or clears every remaining-schedule strip and/or every VS strip on that tab according to the two draft checkboxes (VS only for rows with a current-week `vsMatchup`). **Filter** (Lineup / Stats only — omitted on Players, which already has position pills): a matching boxed filter-icon control (three stacked pill bars; label to the right shows the applied choice, e.g. **View All** / **QB Only**, vertically centered with the icon) opens a single-select checklist (**View All** default, **QB Only**, **RB Only**, **WR Only**, **Flex Only** = RB / WR / TE, **D Only**, **K Only**); choosing a box alone does nothing until **Filter** is clicked (applies + closes). Reopening restores the last applied choice. **Reset** under Filter sets **View All**, applies, and closes. Filtered Lineup/Stats keep a `min-height` from the last **View All** layout (per tab) so a short filtered list doesn’t shrink the page under the absolute filter menu and force scrollbars. Stats and Players rows use the same calendar toggle + remaining-slate strip as Lineup (Players FA fetch uses `includeSos=1`). While `completedWeeks < 4`, dual aisles (**ESPN**/league-host label + **BLENDED**); from week 4 on only the league-host OPRK aisle (label still shown — ESPN / Sleeper / CBS from `platform`).

**FA expand:** A person/+ icon sits next to the calendar. Click loads free agents / waivers for that row’s position (`GET /api/team/free-agents?position=` — FLEX slot uses FLEX; otherwise the player’s position; fetch **50** skill / **80** D/ST·K from ESPN’s %Rost pool, then keep the top **8** / **20** by week **Proj**) and shows a condensed one-line strip (Player+team/pos inline · calendar SOS toggle · Type · Opp · Proj · OPRK · %Rost · +/- · PRK · FPTS · Avg; Score/Last come from game-log FPTS like the Players tab). Each FA row’s calendar expands the same league-host / BLENDED remaining-slate strip as Lineup (BLENDED only while `completedWeeks < 4`). Sortable headers (not Opp) use `SortableStatTh` (reserved arrow slot + matching numeric cell pad) so ↑/↓ never shifts columns; active sort uses the compact header pill + ↑/↓ and paints a seamless full-cell green wash on body cells only (no value shift; survives row hover); default / cycle-off order is **Proj** desc; cycle **desc → asc → default**; **PRK** / **OPRK** cycle **asc → desc → default** (1 = best / toughest). Roster-row SOS, VS, and FA can stay open together (and FA rows keep their own calendar SOS); when stacked the order under the player is **schedule → VS → FA**.

**Vs expand:** A **VS** icon sits next to the FA toggle (Lineup) or remaining-schedule calendar (Stats / Players) when the player has a current-week opponent (`vsMatchup` — roster via `enrichMyTeam`, free agents via `espnFreeAgents` / `buildVsPosMatchup`; omitted on bye). Click opens a compact strip under the row with **Week {n} Matchup:** above `{OPP} vs {POS}` (values show league rank in parentheses, **1 = fewest allowed / toughest**, same OPRK text heat). Fixed aisle: **Rank vs {POS}** (ESPN OPRK), **FPA to {POS}** (season fantasy pts allowed / game to the **whole position** from `espn-oprk` averages), **L3 FPA to {POS}** (mean of the last ≤3 completed weeks’ PPR allowed by that defense vs the position, from nflverse weekly `player_stats` cache), **TDs to {POS}** (season **total** — QB: pass+rush from nflverse; RB/WR/TE: rush+rec from `td-defense-by-pos`). Yards aisle (vertical divider on desktop; top rule on narrow layouts): **Passing** (QB) / **Receiving** (RB/WR/TE) vs **Rushing** toggle sits in the header row; **Yds/g**, **L3 Yds/g**, and split **Pass/Rec/Rush TDs** — all from nflverse weekly (`passing_yards` / `receiving_yards` / `rushing_yards` + matching TD columns; QB pass yards are **net**, not ESPN byteam gross). Default toggle = **Rushing** for RB, Passing/Receiving otherwise. Uses the player’s actual position (FLEX → RB/WR/TE). K and D/ST show OPRK + season FPA when present; yards/TDs stay — (no toggle). Same strip on **Stats** and **Players**; when both schedule and VS are open, schedule sits above the VS strip.

### Stats view

Position-group tables (ESPN-style), not Starters/Bench:

| Section | Stat groups |
|---------|-------------|
| Quarterbacks | Opp/Status · Passing (C/A, PCT, YDS, TD, INT, FUML) · Rushing (CAR, YDS, TD) · Usage (SNAP%) · Research (%Rost, +/-) · Season (RATE = NFL passer rating, TOT, AVG) |
| Backs and Receivers | Opp/Status · Rushing · Receiving (REC, YDS, AVG, TD, TAR, TAR/G, TOT TD) · Usage (SNAP%, RTE%, AIR, YAC, aDOT, CARY%) · Research · Fantasy Pts |
| Team D/ST | Opp/Status · TD/INT/FR/SCK/SFTY/BLK/PA/YA · Research · Fantasy Pts |
| Kickers | Opp/Status · 1-39 / 40-49 / 50+ / TOT / XP · Research · Fantasy Pts |

**Data:** First open of Stats calls `GET /api/team?stats=1`, which runs `attachSeasonStats` (`server/src/services/myTeamSeasonStats.ts`): aggregates `buildPlayerGameLog` YTD cells for QB / RB-WR-TE / K (ESPN athlete gamelog `?season=` only — no bare-URL prior-season fallback) and **D/ST** (ESPN fantasy weekly actuals → TD/INT/FR/SCK/SFTY/BLK/PA/YA; falls back to `defense-stats-{season}.csv` PA/YA only when the fantasy log is empty). Usage columns (snap %, **RTE%**, air yards, YAC, aDOT, carry share) come from `player-usage-{season}.csv` (`fetch-player-usage`, Tue/Fri). Fantasy TOT/AVG reuse enriched FPTS/Avg. %Rost reuses mRoster ownership (same as Lineup). Players with no games yet show —. Bio **Game Log** for D/ST uses the same fantasy weekly path (not athlete gamelog).

**RTE% (2026 interim):** nflverse `pbp_participation` is postseason-only for FTN years, so mid-season route charts are missing. Enrichment estimates routes as ESPN `receivingYards / yardsPerRouteRun`, then `routes / team REG qb_dropbacks` from nflverse PBP (capped at 100). Season-long denominator includes weeks the player missed.

**Shown as — for now:** Research +/- (no ownership-delta feed); kicker distance splits (1-39 / 40-49 / 50+). No MOVE / headshots.

**Sorting:** Same cycle as Players / FA strip: most columns **desc → asc → default**; lower-is-better keys (**INT**, **FUML**, **PA**, **YA**, and any **PRK**/**OPRK**) use **asc → desc → default**. **Player** is sortable; Slot / Opp / Status and empty columns (+/-, placeholder kicker splits) are not. Missing values sort last; each table sorts independently. Stats tables share a fixed-width Slot / Player / Opp / Status rail (auto layout for the rest) so QB **Passing** and Backs&Receivers **Rushing** start on the same X without crushing value/header alignment.

**Value tooltips:** Hover a numeric Stats cell for NFL positional rank among the same position (e.g. `12th of 84 WR`). Pools: nflverse `player_stats` (box), `player-usage` (SNAP%/RTE%/AIR/YAC/aDOT/CARY%), `fantasy-points` (TOT/AVG), defense-stats (PA/YA). Lower-is-better for INT / FUML / PA / YA.

**SOS / VS:** Same remaining-schedule calendar and **VS** strip as Lineup (roster `sosSlate` / `oprkSlate` / `vsMatchup` from `GET /api/team`). **Show All:** calendar / VS icon checkboxes with **Apply** in the same box sync each strip type to its draft checkbox.

## Persistence

`data/my-team/{season}.json`: lean snapshot (`season`, `platform` (`espn` | `sleeper` | `cbs`), `leagueId`, `teamId`, `teamName`, `importedAt`, `refreshedAt`, `players[]` with slot + injury). ESPN import writes `platform: "espn"`; `readMyTeam` defaults missing `platform` to espn. Week/season stats are joined at serve time (`server/src/services/myTeamEnrich.ts`) into `MyTeamRosterView`. Season counting stats (`seasonStats`) only when `?stats=1`. Bio name-card ranks follow `platform`; WK PROJ prefers roster `projectedPoints` when on the import, else compare `weekProjectedPoints` (ESPN leaguedefaults by athlete/D/ST id).

### Players view (free agents)

ESPN-league free-agent / waiver pool (`GET /api/team/free-agents`), ESPN feed is `%Rost` desc but the Players tab **defaults to week Proj desc** without header/column highlight until a sort is clicked (cycle-off clears highlight and falls back to Proj); **limit 150** per position filter (server cap 250) so low-owned / high-Last waiver hits still show when re-sorting (a 50-cap dropped names like Omar Cooper Jr. / Jahan Dotson). Uses saved/env ESPN cookies + imported `leagueId`. Position pills (All / QB / RB / WR / TE / FLEX / D/ST / K) map to ESPN `filterSlotIds`; client search filters the loaded page. Table (app `mt-table` / `mt-fa-table` theme — **not** Lineup’s `colgroup` schema; Players uses its own `colgroup` + `table-layout: fixed` + `width: 100%` so the group header doesn’t size col 1 from the short “Players” label — Player **13rem**, Type **4.5rem** for `WA (Thu)`, Opp **2.85rem**, Status **5.75rem**, nums **3.15rem**; name flex-grows with ellipsis, icons don’t shrink). Group headers: **Players** | **NFL Week N** (spans Type through +/-; no separate top **Type** label) | **{season} Season**. Columns: Player · Type (`FA` / `WA (Wed)`) · Opp · Status · Proj · Score · OPRK · %ST · %Rost · +/- · PRK · FPTS · Avg · Last. FA `kona_player_info` only returns week **Proj** (not weekly actuals), so **Score** / **Last** prefer a batched leaguedefaults `filterIds` fetch, then fall back to athlete gamelog for leftovers. Players tab passes `includeSos=1` so each row gets remaining-schedule slates + `vsMatchup` (calendar + **VS** icons; same strips as Lineup/Stats). Default without the flag: SOS/OPRK slates only when `limit ≤ 25` (Lineup FA strip); `vsMatchup` is always attached when there is a current-week opponent. Sortable headers (Opp / Status not sortable; **PRK** / **OPRK** asc-first). Name opens the same bio modal (roster prev/next nav disabled when the player is not on the roster). No Add / Watch actions (ESPN-only). Cached ~2 minutes server-side per position/limit/`includeSos`.

## API

| Method | Path | Role |
|--------|------|------|
| `GET` | `/api/team/defaults` | Prefill league id, season, preferred team name, saved-auth flag |
| `GET` | `/api/team` | Enriched roster view; `?stats=1` adds YTD `seasonStats`; 404 if none |
| `GET` | `/api/team/free-agents` | ESPN FA/waiver pool for the imported league; `?position=` + `?limit=` |
| `POST` | `/api/team/espn/preview` | Team list + roster preview |
| `POST` | `/api/team/espn/confirm` | Persist snapshot; returns enriched view |
| `POST` | `/api/team/espn/refresh` | Sync; returns enriched view |
