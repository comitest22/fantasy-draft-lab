# Positional Scarcity and Runs

## Scarcity by position (PPR redraft)

| Position | Scarcity | Notes |
|----------|----------|-------|
| RB | High early | Top-24 RBs go fast; drop-off after RB24 is steep |
| WR | Moderate | Deep position; PPR boosts mid-tier WR value |
| TE | High at top | Kelce/Andrews tier creates tier break; otherwise wait |
| QB | Low | Deep position; wait unless elite value |

## What is a "run"?
A run occurs when 3+ consecutive picks are the same position. Example: RB-RB-RB in rounds 5-6.

## When to join a run
- You need that position and the player is within 1 round of ADP.
- The run creates a discount at another position you'll pick next (e.g., WR run lets you get RB value).

## When to fade a run
- You'd be reaching 2+ rounds above ADP.
- You're forcing a need (e.g., taking TE because "everyone else did").
- Better value exists at a scarce position that won't last.

## Practical rule
Before each pick ask: "Am I choosing this player because of need, fear of a run, or because they're the best value on the board?"

Best value on the board should win in rounds 1-8.
